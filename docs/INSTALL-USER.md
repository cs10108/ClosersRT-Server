# 用户安装与汉化指南

## 需要的文件

| 文件 | 用途 |
|---|---|
| 游戏本体 APK（closersRT-game-*.apk） | 游戏本 |
| 服务器 APK（Closers-RTServer-*.apk） | 本机服务器 App |
| 内容包 zip（另发） | 游戏资源（PakCache 等） |
| 语言包 zip（ClosersRT-langpack-*.zip） | 简中 + 韩文，只需上传一次 |

## 步骤

```
1. 安装两个 APK
2. 内容包 zip 放到手机 Download/
3. 打开 Closers-RTServer → 按 START SERVER
4. 浏览器开 127.0.0.1:8080 → SELECT CONTENT ZIP → 选内容包
5. 語言 Language 区 → 上傳語言包 zip（一次，中文+韩文同时入库）
6. 按「简体中文」→ 完全关闭游戏再重开 → 汉化版
```

## 之后每次玩

```
打开 App → 按 START SERVER → 开游戏
```

语言切换：App 或 Web 皆可，切换后重启游戏。

## 存档

Web 界面存档区：导出（下载 JSON）/ 导入 / 重设基准预设。
导入前系统会自动备份当前存档。

## 常见问题

**按了中文但游戏还是韩文？**
必须完全关闭游戏再开。客户端每次启动才重新解包语言文件。

**按「中文」没反应？**
看语言区当前语言下面有没有包大小。没有就是语言包还没上传，先上传 zip。

**游戏登录卡住？**
把 App 的省电设置改成「无限制」。

**换手机/重装？**
导出存档 JSON 留好；语言包 zip 重新上传一次即可（服务器数据在 App 内部存储）。
